🔐 One-time setup

This page runs only in your browser. Nothing is sent anywhere except to api.github.com with your token. Delete this page from the site once you are done.

1 · Your details

2 · Your generated password

Save this now in a password manager – it is shown only once and cannot be recovered.

3 · Add this file to the website repo

Save as config.js and upload it to the public repo next to index.html (GitHub → Add file → Upload files). It contains your token encrypted with the password above.

4 · Upload your starting data to the private repo

Choose starter-data-PRIVATE.json from the package (it is stored in the repo as data.json).
